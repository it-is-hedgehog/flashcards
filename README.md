## Как использовать

**Главный экран:**
- Сверху статистика: К повтору / Новых / Всего
- Кнопка "Учить всё" — повтор по всем колодам подряд
- Список колод — клик → учить выбранную

**Учить карточку:**
1. Видишь вопрос
2. Думаешь
3. Нажимаешь "Показать ответ"
4. Видишь ответ + 4 кнопки оценки

**4 кнопки оценки:**
| Кнопка | Значение | Когда показать снова |
|---|---|---|
| 😵 Забыл | не помню | < 1 мин (в этой же сессии) |
| 😐 Тяжело | вспомнил с трудом | ~1 день |
| 🙂 Норм | вспомнил нормально | ~4 дня (растёт со временем) |
| 😎 Легко | вспомнил мгновенно | ~7 дней (растёт быстрее) |

**Алгоритм** автоматически рассчитывает интервал — чем чаще "легко", тем дольше до следующего показа.

**Меню (☰):**
- Тема (Авто / Светлая / Тёмная)
- Лимит карточек в день (default 30)
- Экспорт/импорт прогресса (JSON-бэкап)
- Сброс прогресса

**Горячие клавиши (на desktop):**
- `Space` — показать ответ
- `1` `2` `3` `4` — оценить карточку

## Деплой на iPhone (план на 06.06)

PWA на iOS требует HTTPS. Способы:

### Вариант 1: GitHub Pages (рекомендую)

1. Создать публичный репозиторий, например `dscards`
2. Запушить все файлы
3. В Settings → Pages → Source: `main` branch
4. Через минуту доступен по адресу `https://<username>.github.io/dscards/`
5. На iPhone — Safari → этот URL → кнопка Share → "Добавить на главный экран"

После добавления — иконка на главном экране, работает offline.

### Вариант 2: Локальный туннель (для теста)

```bash
# через ngrok или cloudflared
cloudflared tunnel --url http://localhost:8765
```

Получишь публичный HTTPS-URL — открой на iPhone, Add to Home Screen.

## Пополнение карточек (после каждой DSB-сессии)

Я (ИИ-наставник) после каждой сессии:
1. Извлеку новые маркеры из `time_tracking.md`
2. Сформирую новые карточки с уникальными ID
3. Добавлю в `deck.json` к существующим
4. Запушу в репо

Service Worker автоматически подтянет новые карточки при следующем открытии (когда есть сеть).

**Прогресс по старым карточкам сохраняется** — IndexedDB/localStorage хранит ID + ease/interval/due. Новые карточки приходят как "новые" в очередь, старые остаются с своим прогрессом.

## Формат карточки

```json
{
  "id": "d7019",
  "deck": "07 DSB7 Pandas",
  "front": "Что такое `cut` в pandas?",
  "back": "Разбивка значений на категории по интервалам.\n`pd.cut(df['hour'], bins=[0,11,17,24], labels=['утро','день','вечер'])`",
  "tags": ["pandas", "cut", "dsb7"]
}
```

**Поддерживается markdown в тексте:**
- `\`code\`` — моноширинный шрифт
- `**bold**` — жирный
- `\n` — перенос строки
